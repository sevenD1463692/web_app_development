# PRD (Product Requirements Document) - MyLife 全方位個人生活管理系統

## 1. 專案概述
- **背景與動機**：現代人生活圈廣泛且忙碌，常常需要切換多個不同的應用程式來管理任務、記帳、紀錄筆記、報名講座以及收藏食譜。這不僅導致資料分散，也降低了生活管理的效率。我們希望打造一個結合五大功能的單一整合平台。
- **目標用戶**：希望提升生活效率、集中管理個人資訊，以及重視生活品質的學生、上班族與家庭主婦 / 夫。
- **核心價值主張**：以「單一平台、全方位管理」為核心概念，降低使用者跨應用程式切換的成本，讓生活紀錄與規劃變得更直觀、輕鬆且高效率。

## 2. 功能需求
以下為系統涵蓋的 5 大核心功能與對應的使用者故事：

1. **任務管理系統**
   - **使用者故事**：作為一名使用者，我希望可以建立、編輯、刪除與標記完成待辦任務，以便我能清楚掌握並追蹤每日需要處理的各種事項。
2. **個人記帳簿**
   - **使用者故事**：作為一名重視理財的使用者，我希望可以記錄每日的收入與支出，並查看結餘，以便我能有效掌控與回顧個人的財務狀況。
3. **讀書筆記本**
   - **使用者故事**：作為一名熱愛學習的使用者，我希望可以記錄我閱讀過的書籍與各章節重點心得，以便未來能夠快速複習與尋找過去累積的知識。
4. **活動報名系統**
   - **使用者故事**：作為一名喜歡參加活動的使用者，我希望可以瀏覽平台上即將舉辦的活動並進行線上報名，以便我能擴展興趣圈或參與課程。
5. **食譜收藏夾**
   - **使用者故事**：作為一名烹飪愛好者，我希望可以收藏、分類並記錄自己喜歡的食譜，以便我在下次下廚時能夠快速找到對應的食材準備與步驟。

## 3. 非功能需求
- **技術限制**：
  - 後端框架：使用 Python 的 **Flask** 框架。
  - 前端渲染：使用 **Jinja2** 模板引擎進行畫面渲染。
  - 資料庫：使用 **SQLite** 關聯式資料庫。
- **效能考量**：系統需保持輕量化，頁面載入時間在正常網路環境下應小於 2 秒，確保流暢的操作體驗。
- **安全考量**：
  - 密碼需經過安全雜湊加密（如 Werkzeug security）。
  - 對所有使用者輸入進行檢查，防止 SQL Injection 與 XSS 攻擊。
  - 確保使用者的個人帳務與筆記資料具備相應的隱私權限隔離（不可看見他人資料）。

## 4. MVP 範圍 (Minimum Viable Product)
- **Must Have (必須具備)**：
  - 使用者註冊與登入系統。
  - 任務管理的新增、查看清單與完成標記。
  - 個人記帳的基本收支紀錄。
  - 讀書筆記的基本文字建立與編輯。
- **Should Have (應該具備)**：
  - 食譜的收藏與自訂分類標籤功能。
  - 簡單的活動列表顯示與一鍵報名按鈕。
- **Nice to Have (有了更好)**：
  - 記帳資料的圖表化趨勢分析（如圓餅圖或長條圖）。
  - 各項即將到期的任務或活動的 Email 提醒。
  - 讀書筆記與食譜的公開社群分享功能。
